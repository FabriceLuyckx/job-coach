Every macro emits the same class vocabulary (.section/.entry/.tag/…); each template styles those names itself. `with context` is required — the macros read the render context (profile keys, labels, hidden_sections, photo). Every section carries a `hidden` check keyed on its own data-section value: the CV editor lists a checkbox for each key it finds in the rendered preview, so a new section here needs no frontend change — just the two matching keys (data-section="x" + 'x' not in hidden) and a cveditor.sections.x label. #} {% set hidden = hidden_sections | default([], true) %} {# ── PHOTO ── crop params from cv_design_preferences.photo_crop, applied as pure CSS inside whatever frame the template sizes via `cls`.
