MyJobCoach — read this first
============================

1) UNZIP BEFORE YOU RUN IT.

   Do not double-click MyJobCoach.exe while you are still looking inside the
   .zip file. Windows will appear to open it and then nothing happens.

   Instead: right-click MyJobCoach-windows.zip -> "Extract All..." -> pick a
   place to keep it (Documents is fine) -> open the MyJobCoach folder that
   comes out -> then run MyJobCoach.exe.

   Keep the whole folder together. MyJobCoach.exe does not work on its own.


2) WINDOWS WILL WARN YOU THE FIRST TIME. THIS IS EXPECTED.

   You will see a blue box: "Windows protected your PC".

   Click "More info", then "Run anyway".

   This appears because the app is not code-signed yet (a certificate costs
   money we haven't spent). It is not a virus warning. Your antivirus may
   also flag MyJobCoach.exe for the same reason -- if it does, allow it.


3) FIRST LAUNCH TAKES A MINUTE.

   The app downloads a PDF engine once (~150 MB). A banner shows the
   progress; everything except PDF export works while it finishes.

   The app opens in its own window. Closing that window quits it.
