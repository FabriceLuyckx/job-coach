# Contributing

Thanks for considering a contribution to MyJobCoach.

## Workflow

1. Fork the repo, branch off `main`.
2. Make your change. Dev setup: see `README.md` / `setup.sh`.
3. Open a PR **against `main`**. `stable` is release-only and merged by the maintainer — don't target it.
4. Write [Conventional Commit](https://www.conventionalcommits.org) subjects (`feat:`, `fix:`, `chore:`, ...) — these drive automatic version bumps on release.

## Reporting bugs

Open an [issue](../../issues/new/choose) with the Bug report template — what happened, your OS, and the app version (About modal, sidebar footer) if you have it.
